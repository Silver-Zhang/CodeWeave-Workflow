## 3. 打开文件夹，查看或创建会话

1. 点击顶部“打开文件夹”。
2. 选择运行器上的 `/home/workspace/DevFlower/DevFlower`，确认顶部显示完整路径和环境。
3. 左侧可按Provider或Workflow分组，搜索会话名称；点击会话后，中央显示可见历史消息和结构化执行结果。
4. 工具活动、实际请求和高级证据默认折叠；它们不代表模型隐藏思维链。
5. 点击会话列表加号新建，选择执行配置、模型、推理强度和Ask/Plan/Agent模式。

历史会话仍绑定原HOME、cwd和原生UUID。本次没有把原目录伪装成main目录。若要查看之前的运行和会话，可在目录窗口选择仍被保留的 `/home/workspace/DevFlower/development/model-admission-cas-fix`；其源码与本次主线候选一致，但工作树已不再占用开发分支。只读导入、环境不明或被占用的会话不保证可恢复写入。

模型选择步骤：

1. 点击“刷新模型”，检查来源、更新时间、缓存和错误。
2. 选择已登记的模型、effort和模式。
3. 点击“验证执行”，阅读说明、填写确认意见并确认一次实际原生诊断。调用可能计费，但不发送项目源码或任务。
4. 验证成功后，输入消息，点击发送并核对本次权限预览。

目录发现、操作者登记和执行准入分别检查。准入绑定当前精确配置，通常5分钟有效；配置变化、过期或真实调用失败后需重验。现有批准请求配置为Codex gpt-6.1-sol/xhigh、Claude claude-opus-5-5[1m]/high，以实际当前配置为准。无法由服务证明的物理后端和生效强度仍为unknown。

## 4. 在画布搭建并运行

1. 新建工作流，或从“示例”选择顺序、并发汇合、循环或路由。
2. 从节点库添加节点，拖动卡片调整布局，从上游右端口连到下游左端口。
3. 点击Agent，右侧设置名称、职责、Provider/Profile、会话、模型、effort和模式。
4. 在提示词页填写：本次运行初始化提示词、每轮提示词、输出与交接要求。
5. 高级设置限制工具、权限、超时、预算和输入/输出合同；Ask/Plan由运行器强制只读。
6. 点连线，选择实际传递字段。默认不把完整聊天历史复制到下游。
7. 填写“本次任务”，保存工作流，点击“开始运行”，核对冻结流程、权限和预算后确认。

一次新运行的节点首次执行发送初始化；同一运行的循环、恢复和刷新不重复初始化。设计草稿和运行快照互相独立，编辑下一次流程不会改写已启动运行。

画布支持拖动、框选/多选、复制删除、对齐分布、撤销重做、适应画布、缩略导航。空格或中键平移，滚轮缩放；顶部切换浅色、深色或系统主题。左右侧栏和底部面板可以调整大小，Escape关闭最上层浮层。

## 5. 看清真实进度、交接和下游请求

- 顶部运行总览：当前状态、执行节点、轮次、耗时、等待对象和失败原因。
- 节点：查看等待、执行、交接、人工确认、完成、失败、跳过、取消或状态待确认。
- 点击运行中的连线，打开“数据传递”：核对来源/目标、来源/目标轮次、实际字段、实际内容、发送/接收状态及产物身份。
- 点击下游Agent的“实际运行”：查看初始化、每轮指令、当前上游输入、输出要求、完整可见请求及原生回执。
- 历史运行从画布运行选择器打开，不需要手工寻找run_id。

条件/路由按声明字段确定性执行；未选分支显示跳过，未命中时走已配置默认分支或明确停止。汇合等待声明输入，循环有最多五轮上限。模型输出不能授予权限或批准交付。

## 6. 暂停、关闭与原生终端

| 操作 | 实际效果 |
|---|---|
| 暂停 | 停止调度新节点，当前进程继续 |
| 继续/核验恢复 | 先检查已有运行和进程，不盲目重放 |
| 停止工作流 | 取消本任务拥有的执行进程 |
| 关闭标签或检查面板 | 只关闭显示，不删除历史、不停止工作流 |
| 关闭终端视图 | 断开显示，不等于结束CLI |
| “关闭此终端” | 明确停止该终端进程，历史保留 |

从会话页签进入“原生终端”→“打开同一原生会话”，核对原环境后确认。已被工作流或其他终端占用时拒绝第二写入者。刷新页面恢复显示，不会重复启动Agent；网络错误先核验，不连续新建运行。
