# v0.2-A 验收合同

状态：未来实现的验收标准，不是当前测试结果。全部证据绑定 Controller/配置/候选/CLI 版本。单元、模拟进程、真实模型、真实 Git 交付分开计数；需要的能力缺失写 BLOCKED，不以 Skip 当通过。

| ID | 核心判据 | 必需实测 |
|---|---|---|
| A01 | 没有批准的授权不能运行写任务或交付 | 缺授权、错误分支、越界路径、修改授权哈希全部拒绝 |
| A02 | 一任务/目标只允许一个写入者 | 两控制器竞争；活锁保护；旧 PID 已复用不误杀 |
| A03 | 状态与事件原子、恢复不伪完成 | 状态落盘前后注入中断；恢复仍知道未完成阶段 |
| A04 | 完整候选包含新增/删除/mode/链接 | staged+unstaged+untracked 测试；树外链接不能被读取；审查期间改变内容使证据失效 |
| A05 | Agent 无法自己颁发交付许可 | 实施者改报告/控制状态/远端凭据的探针被隔离；无实际隔离自动门关闭 |
| A06 | 进程启动和终态真实 | 认证失败、stderr 洪水、非法 JSON、缺终态、超时、取消，只终止自身进程组 |
| A07 | 测试不是文字 PASS | exit0+0tests、关键Skip、旧candidate、改判据、伪造结果路径均不通过 |
| A08 | 审核身份和裁决一致 | 错run/round/contract/hash、旧ACCEPT、ACCEPT+P1/FAIL、输出被截断均不交付 |
| A09 | 修复闭环有界且可恢复 | 假CLI拒绝后修复、新候选重验重审；5轮上限、2次基础重试耗尽均阻断 |
| A10 | 会话不能串项目/角色 | 明确UUID恢复、模型/effort变化、会话占用与恢复失败；不 --last 猜测 |
| A11 | 查询与日志安全 | status不改源码/启动Agent；可分页有界；日志不含令牌/隐藏推理/未经授权源码 |
| A12 | Git commit对应审核树 | 新增删改mode、hook/filter改内容、他人改动、用户index保护、commit中断后不重复 |
| A13 | Git push可幂等恢复 | 成功但响应丢失、远端冲突、错误仓库、源码成功工作流失败；不得强推 |
| A14 | 原工作流兼容 | init/new/index/check与原基线回归；main/flow无project实例；旧档案保持 |
| A15 | 真实多Agent试点 | 实际Codex、实际Claude、独立候选、真实命令，至少一次修复再复审；不是模型模拟 |
| A16 | Controller自举可信 | 待审新controller不为自身代码签发通过/推送；验收由固定旧工具或外部监督执行 |

## 分阶段完成标准

A0 交付：本地可运行的 doctor/status、状态存储、候选冻结、gate及故障夹具；A01–A09/A11/A14的相应模拟与确定性测试。无真实模型声明。

A1 交付：真实适配器、会话记录、受控真实验证、拒绝→修复→复审；补齐A05/A06/A10/A15。既有模型认证不可用则停在明确BLOCKED，不新购服务或伪造结果。

A2 交付：本地 bare remote 的A12/A13完整负例，确认没有自动merge/tag/release；再进行获准的小型远端试点。不得先用正在开发的 CodeWeave 或 RMC 来验证破坏性失败。

## 记录与判断

模拟服务返回故意矛盾的 ACCEPT 用来测试 gate，不算“Claude审核”；人工断开进程用来测试恢复，不假称服务自然故障。每项测试保存预期、实际、命令、退出码、候选及可复现脚本。

Controller不声称判断代码绝对正确；它保证已批准的流程和验证条件没有被跳过。最终裁决 ACCEPT、ACCEPT_WITH_LIMITATIONS、NEEDS_CORRECTION、BLOCKED 分开；本期自动交付只接受无阻塞的 ACCEPT。

现有基线测试须在本地完整 checkout 后重新运行。设计准备环境仅做源码/合同核对，不能复用历史的24项通过报告宣称本轮已运行。
